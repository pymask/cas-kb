# 企业会计准则知识库

一个方便查阅中国企业会计准则及相关官方资料的知识库。你可以按准则、会计科目或关键词查找内容，也可以查看官方资料的更新记录和新旧版本文字差异。

**在线使用：[打开企业会计准则知识库](https://pymask.github.io/cas-kb/)**

本项目独立整理公开资料，并非财政部或证监会官方网站。引用或处理具体业务时，请点击页面中的“官方原文”核对文件、适用对象和生效时间。

## 第一次使用

1. 打开[在线知识库](https://pymask.github.io/cas-kb/)。如果页面要求输入访问口令，请使用维护者提供的口令；没有口令时可联系维护者。
2. 进入后先看“工作台”，这里有准则查询、官方资料、知识体系和更新记录的入口。
3. 在手机上使用时，点击顶部的 **☰** 打开左侧目录；电脑上可直接从左侧选择。

访问口令只用于浏览器端的阅读入口，不是账号登录或安全权限控制；仓库内容是公开的。

## 怎样查找内容

| 想做什么 | 操作方法 |
| --- | --- |
| 查某部准则或解释 | 在左侧选择 **按准则查询**，展开相应准则、解释、实施问答或应用案例，再点击目录中的条目。 |
| 查某个会计科目 | 在左侧选择 **按会计科目查询**，选择科目类别及科目名称，查看已经建立关联的条文、解释、问答和案例。没有关联结果不代表该科目不适用任何准则。 |
| 搜索关键词或文号 | 在顶部搜索框输入内容，例如“收入”“租赁负债”或文号，按 **Enter** 查看结果。搜索结果中的入口也可跳转至相关官方资料。 |
| 查最新采集的官方文件 | 点击左侧 **官方资料**，可按关键词和资料类型筛选；打开文件后可查阅正文、已提取的附件文字和官方来源链接。 |
| 理解资料之间的关系 | 点击 **知识体系**，按照“准则依据 → 实施指导 → 政策与年报 → 监管参考”的路径浏览，也可查看已有的新旧准则文字对照。 |
| 查更新和差异 | 点击 **更新日志**，查看最近检查时间、异常来源、历史检查及采集内容的版本变化。 |

阅读具体条文时，页面会展示文号、发布日期、适用状态等信息；点击 **官方原文** 可到发布机关网站核对。历史资料中的效力标记并非全部经过逐条复核，请特别留意“待核验”和分批实施提示。

## 知识库收录什么

- **准则与解释**：基本准则、具体准则及准则解释，部分准则保留新旧版本。
- **官方实施指导**：财政部的实施问答、应用案例、政策解读和实施情况分析等。
- **监管参考**：已登记的证监会会计监管指引和年度财务报告会计监管报告等；使用时需核对其适用范围。
- **版本对照**：已收录的部分新旧准则文字对照，以及同一官方来源的采集版本变化。

资料来自[财政部会计司](https://kjs.mof.gov.cn/)及[中国证监会](https://www.csrc.gov.cn/)等官方公开渠道。知识库按登记来源采集，**不代表覆盖全部官方文件**；部分文件以附件发布，扫描件或未能解析的附件需要打开官方原件查看。

## 更新功能如何使用

系统计划在北京时间每天 **09:17 和 21:17** 检查已登记来源，实际运行时间可能受 GitHub 调度影响。采集成功后，官方资料库会更新正文并保留版本；网站的 **更新日志** 可查看最近检查时间、检查范围、异常和文字差异。

- **首次采集**表示该文件首次进入本库，不一定是官方刚发布。
- **采集文本变化**可能来自官方内容变化，也可能来自提取程序的改进；文字差异本身不是会计处理影响结论。
- 如果显示**检查不完整**，请展开来源检查明细。无法成功读取的资料会保留上一次可用正文，请到官方来源核对。
- 页面上的**刷新检查记录**只重新读取已有结果，不会立即启动抓取。需要立即检查时，仓库维护者可在 [GitHub Actions](https://github.com/pymask/cas-kb/actions/workflows/update-check.yml) 中选择 **Run workflow**。

自动采集会更新官方资料库，不会自动改写历史条文的效力、科目关联或人工修订。草案也不会被自动视为正式生效文件。

## 给维护者

本地预览需要 Python 及项目依赖。在仓库目录下运行：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build.py
python3 -m http.server 8765
```

然后在浏览器打开 `http://localhost:8765`。运行测试和数据校验：

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/validate.py
```

自动更新与发布使用 `.github/workflows/update-check.yml`；来源配置、正文快照和差异记录分别保存在 `data/sources.json`、`data/versions/` 和 `data/changes.json`。部署使用 GitHub Pages 的 **GitHub Actions** 来源。Linux 环境解析旧版 DOC 附件需要 `antiword`，macOS 可使用系统 `textutil`。更多检查结果和已知边界见[项目检查与改造记录](docs/audit.md)。
